When performance matters more than Ruby ergonomics, libemf2svg is the C
implementation. The Ruby ecosystem wraps this via
[`emf2svg-ruby`](/projects/#emf2svg-ruby) or uses the pure-Ruby
[`emfsvg`](/projects/#emfsvg) instead.
