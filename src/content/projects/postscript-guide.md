If you are touching PostScript for the first time while debugging an EPS
pipeline, start here. The guide covers:

- **PostScript levels** — what Level 1, 2, and 3 actually added
- **Language syntax** — tokens, objects, operators, procedures, arrays,
  dictionaries, strings, data types
- **Operator reference** — every command, organized by category
- **Usage guides** — basic and advanced tutorials with runnable examples

Hosted at [claricle.github.io/postscript-guide/](https://claricle.github.io/postscript-guide/).
